# Third-party software

Flowbit is built on the open-source projects below. Each keeps its own license; this file lists
them so the notices travel with the app.

## Bundled programs and assets

| Component | License | Source |
|---|---|---|
| mpv (`resources/mpv/mpv.exe`), Windows build 20261018 | GPL-2.0-or-later | https://github.com/mpv-player/mpv, built by https://github.com/shinchiro/mpv-winbuild-cmake |
| librqbit 9.0.1, patched (`src-tauri/patches/librqbit`) | Apache-2.0 | https://github.com/ikatson/rqbit (changes: `patches/librqbit/PATCHES.md`) |
| Manrope font | SIL Open Font License 1.1 (`ui/fonts/Manrope-OFL.txt`) | https://github.com/sharanda/manrope |
| JetBrains Mono font | SIL Open Font License 1.1 (`ui/fonts/JetBrainsMono-OFL.txt`) | https://github.com/JetBrains/JetBrainsMono |

mpv is a separate program that Flowbit starts; it is not linked into Flowbit. Its complete source
code is available at the links above.

The window uses Microsoft Edge WebView2, which is part of Windows and is not shipped with Flowbit.
